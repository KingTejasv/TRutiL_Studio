# Contributing to TRutiL Studio

First off, thank you for considering contributing to TRutiL Studio! It's people like you that make TRutiL Studio such a great tool.

## How to Contribute

### Reporting Bugs
This section guides you through submitting a bug report for TRutiL Studio. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related reports.

- **Check existing issues:** Before creating bug reports, please check existing issues as you might find out that you don't need to create one.
- **Use the bug report template:** We provide an issue template for bugs. Please fill it out completely.

### Suggesting Enhancements
This section guides you through submitting an enhancement suggestion for TRutiL Studio, including completely new features and minor improvements to existing functionality.

- **Use the feature request template:** We provide an issue template for feature requests. Please fill it out completely.

### Pull Requests
- Please check the open issues or open a new issue to start a discussion around a feature idea or a bug.
- Fork the repository, create a branch, and make your changes.
- Ensure your code follows the existing style and is well-documented.
- Test your changes thoroughly.
- Submit a Pull Request targeting the `main` branch, and fill out the provided Pull Request template.

## Local Development Setup

1. Fork the repo and clone it locally.
2. Run `npm install` to install all dependencies.
3. Run `npm start` to run the application in development mode.
4. Make your changes and test them locally.
5. Create a pull request when you are ready.

Thank you for contributing!
