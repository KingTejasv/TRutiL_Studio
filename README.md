# TRutiL Studio Offline

Welcome to **TRutiL Studio Offline**, a powerful desktop application built with Electron.

## 🌟 Features

- **Offline Capabilities**: Access your essential tools without needing an internet connection.
- **Cross-Platform**: Built on Electron, ensuring a smooth experience on Windows (and potentially other platforms).
- **Fast and Responsive**: Designed for performance and a great user experience.

## 🚀 Installation

To get started with TRutiL Studio Offline on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/KingTejasv/TRutiL_Studio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd TRutiL_Studio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

## 💻 Usage

To run the application locally in development mode:

```bash
npm start
```

To build the application for production (Windows):

```bash
npm run build
```

## 🛠️ Built With

*   [Electron](https://electronjs.org/) - Framework for building cross-platform desktop apps with web technologies
*   [Node.js](https://nodejs.org/) - JavaScript runtime environment
